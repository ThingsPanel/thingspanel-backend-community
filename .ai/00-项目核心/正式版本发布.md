# 正式版本发布

前端 master、后端 main 各发布同名 v 前缀标签；日常推送仍部署测试服。Release 固定标签代码，不包含本地未提交的场景执行改动。

前端 Release 发布静态包及 thingspanel-vue 双架构镜像。后端 Release 协调各平台资源包、thingspanel-go、thingspanel-mosquitto 和 thingspanel-encore 镜像，均推送既有 Docker Hub、GHCR 与阿里云仓库。Encore 使用固定 1.58.6 CLI，原生业务与通知核心共用镜像、分别配置。

部署由已有 ThingsPanel/thingspanel-installer 仓库的 docker-compose.yml 负责，不在后端另外生成 Linux Compose 发布包。该 Compose 已加入 Encore、通知与定时服务，并将 GMQTT 换为现有认证插件的 Mosquitto/Owner。安装器保留独立发布流程，不从后端触发旧 thingspanel-installation Windows 安装器。

输入为明确版本标签，禁止 latest 或当前分支冒充标签；三个仓库镜像推送及双架构验证后上传镜像清单。自托管数据库迁移、独立服务凭据及 Broker 设备允许范围按照安装器配置说明准备，镜像发布不等于已完成全新主机部署验收。

20261029 v1.3.0 前端、后端、Encore 已发布。此前误增的 Linux bundle 打包任务撤销，Broker 镜像此前三个仓库推送成功；其首次清单读取遇到 Docker Hub 500，用户纠正范围后停止额外重跑，不把整条旧流程标为成功。

入口：.github/workflows/release.yml、build-release.yml、docker-image-build.yml、encore-image-build.yml；安装器 docker-compose.yml、config/native/。用户要求停止业务回归，本次仅配置检查，不创建额外版本。
