# 自动化引擎

## 职责与边界

社区后端继续接收设备消息和下发命令；独立 Encore automation 负责新规则、场景、告警和执行记录。原生物模型及通知仍由原模块提供，自动化不直接读写其他服务数据库。

## 已确认的集成规则（20261028）

依据合并评估和用户后续明确授权，已合入自动化来源历史并通过主线自动部署；当前继续执行用户确认的新引擎真实闭环验收。

- 后端实际生效的引擎是页面与上报的共同依据。默认 legacy；当前 Mosquitto ingress_v1 配置 native 时要求完整服务配置，缺失则启动失败，不切回旧引擎。前端不得自行猜测模式或在新服务失败时改写旧库。每次业务操作读取实际模式；原生专属页面在 legacy 下明确拒绝，设备旧联动列表继续可用。
- 告警通知保留“默认策略”和“显式策略”的区别。新告警策略记录选择意图；告警状态变化时通过社区受限服务读取接口解析当时有效的原生组与修订，并冻结在本次 outbox。无默认只记告警；默认/显式策略不可用时保留告警及不可发送的记录，不改选其他策略。重试不重新解析默认。
- 通知策略读取使用已有 source reader 的独立凭据、部署与租户允许列表；不复用用户 JWT 作为跨租户服务权限。新增接口只返回策略快照，不返回联系人或凭据。
- 动作编辑保留 1.3 原生命令标识选择及参数校验；只合入新接口、空数据保护和示例值修复。
- 社区库会在启动时应用命令守卫表，不能声明没有迁移。自动化库升级和已有规则迁移是两件事。正式启用前须完成数据迁移及对账，回退不会把新规则自动写回旧库。纯测试环境已获用户授权用独立验收租户切换 native，旧规则迁移仍待完成。

## 验收与入口

### 20261029 真实链路验收接线

验收时发现 Mosquitto `ingress_v1` 将自动化意图写入 `broker_ingress_effects`，消费者此前只读取旧场景。现已补齐 native 消费分支：持久化意图短事务领取，网络转发在事务外执行；effect ID 作为稳定上报 ID，重试由新引擎去重，不同时调用旧引擎。

上报、设备目录和命令回调使用独立服务凭据及部署标识。租户来自社区可信上报记录或新引擎已鉴权的规则上下文，不使用固定用户 JWT 承载全站权限。服务接口不向浏览器代理开放；缺少凭据拒绝调用，不切回旧引擎。

命令复用现有设备编码、持久化命令队列、路由快照与代际校验，记录独立的新引擎服务来源。发送前仍验证目标租户及设备当前路由；不建立第二套 MQTT 下发实现。验收必须同时取得可信 MQTT receipt、新引擎 run、持久化命令及验收设备收到的唯一标记。

`5d092080`、`2ffcbc6e` 已经主线自动部署并在 47.92.253.145 复验：native MQTT 上报→规则→持久化命令→验收客户端通过，run succeeded；重复上报与命令重试没有第二次下发。4 项隔离 PostgreSQL 回归及错误凭据、跨租户、内部入口拦截通过，篡改命令身份和 HTML 200 不能被当作有效受理。PM2 环境已保存 native，验收规则已关闭。定时调度、通知实发、其他动作及场景/告警、浏览器全量和旧规则迁移验收仍待完成。

### 已授权继续实施：定时接线与通知验收

当前定时、等待续跑和 outbox 重试依赖外部 tick，尚无周期触发。现有浏览器用户 tick/recover 接口会扫描全库，不应作为租户接口开放。移除其公开路由，改由部署级服务身份调用内部 tick；每轮先恢复未处理的已持久化上报，再执行已有有界扫描。复用现有 occurrence 唯一键与租约，不另建调度引擎。

测试服由 systemd 每 5 秒唤醒一次独立 oneshot，禁止重叠执行；失败可见并在下一轮重试，不回到旧引擎。凭据从既有私有配置读取，不进入命令行或日志。源码自动部署同时安装及验证该 timer，不能依赖临时手工启动。验收需创建真实到期规则，等待自动唤醒后收到 MQTT 命令，复验重复唤醒不重复下发。

通知继续复用既有通知核心和插件。用户指定实发接收邮箱 421045249@qq.com；先核对现有可用 SMTP 配置，仅向该地址执行验收。若缺少发送渠道凭据，明确记录阻塞，不能用假 SMTP 或接口受理替代实际送达。

定时服务已随 `936a257b` 自动部署，真实到期规则自动下发及重复唤醒无重复执行验收通过。邮件联测发现自动化端发送 schemaVersion=1 和 variables=null，现有通知核心契约要求 1.0 和对象；按已有固定契约修正并增加读取真实 schema 的回归。部署凭据工具也改为读取当前 Encore 的 disable_tls 与环境引用密码格式，不再解析旧明文密码格式。独立验收通知 source 凭据最长 8 小时，当前只用于验收，不能当作永久运营凭据。

默认模式的前端读写走旧接口；native 走新接口；模式查询失败不得自动选库。原生规则入口在 legacy 时不发送原生写请求。默认通知、显式通知、不可用策略、租户越权及重试快照应有回归证据。

入口：internal/uplink/native_automation.go、router/router_init.go、encore-api/automation/runtime/alarm.go、internal/api/notification_member_reader.go。编译、纯逻辑测试与真实部署验收分别记录；定时驱动和通知真实发送未验证前不得声称已可发布。
