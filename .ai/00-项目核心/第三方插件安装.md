# 第三方插件安装

## 职责与边界

本次从 `integrate/ha-plugin-main-20261110` 将 HA 候选集成到社区 main。只集成 HA 安装及必要依赖，不引入 develop 的关系数据库适配、TDengine、CLI 或委托路由改造。

平台超管安装共享插件；租户管理自己的接入点、HA 地址与令牌。宿主机 Agent 执行容器操作，后端通过 Unix socket 和 token 访问 Agent。未配置 `TP_AGENT_SOCKET` / `TP_AGENT_TOKEN_FILE` 时安装引擎不运行，安装接口返回 503。

## 输入输出与主流程

官方签名目录和已准备的镜像 → 超管提交安装 → check / identity / prepare / grant / activate / register / health → 插件启用。平台安装器负责制品准备及 Agent 部署，本次未发布镜像或更改安装器。

插件连接租户 HA，通过 Broker 完成遥测和命令回执。受管身份定期同代次续租；停用、卸载或持续续租失败后吊销，重新启用使用更高代次。卸载保留设备、接入点和历史。

## 已确认的兼容规则（20261110）

用户确认保留旧插件兼容，仅 HA 强制受管身份。五个共享接口允许无 Authorization 的旧插件请求继续执行原有逻辑；携带 Authorization 的请求必须验证身份，验证失败不得降级。无身份请求按真实目标服务判定，homeassistant 一律拒绝，不能通过省略请求中的服务标识读取 HA 接入点或设备。身份有效的请求继续执行服务和租户范围校验。

安装菜单仅 SYS_ADMIN 可见，租户使用现有三方接入页面。不得将历史测试栈的冒烟记录当成本次发行验收。

## 验收与入口

- `internal/plugininstall/`：安装、幂等、身份续租、失联与恢复。
- `internal/pluginidentity/`、`internal/api/plugin_runtime_identity.go`：身份与访问范围。
- `internal/api/plugin_install.go`：仅 SYS_ADMIN 且非 delegated 可安装。
- `sql/33.sql`、`34.sql`、`35.sql`：身份、安装记录、菜单。
- `docs/HA-PLUGIN-HANDOVER.md`：来源验收资料，记录的是其他环境的历史状态。
