## 在页面上如何配置

1. 平台超管进入“系统管理 → 通知配置 → 通知插件”，登记并启用插件，然后授权给目标租户。插件的内部 HTTPS 地址由部署维护，不能复制另一台服务器的 Docker 服务名。
2. 超管在“服务账号”中选择目标租户，创建并验证 App 渠道。UniPush 2.0.0 的云函数、AppID 和 CloudToken 在插件部署侧固定，因此渠道的用户配置为空对象是正常设计。
3. 租户进入“告警 → 通知策略”，新建或编辑策略，选择 App 渠道，再点击“使用设备告警通知”。
4. 选择接收成员，可多选。“App 全部有效手机”会按当前租户、账号、AppID 和有效会话解析设备，不填写 CID。
5. 点击“保存并生效”。当前策略已经发布，能在告警规则的策略选项中使用。
6. 未指定通知策略的告警只有在配置了租户默认策略后才发送通知。当前恢复没有替换租户默认策略。
