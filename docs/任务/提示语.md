## 需求&目的

通过 AI 自动完成 ThingsPanel 物模型模块的**问题分析 → 方案设计 → 代码改造**全流程。AI 对比源码与行业最佳实践，找出设计问题、UX 问题、功能问题；为每个问题生成解决方案；最后拆解为可执行的任务清单，直接驱动 AI 完成代码改造。

## 生成解决方案提示语

```
你是一个AI编程助手。请基于已识别出的 ThingsPanel 物模型模块问题（详见 docs/任务/物模型相关产品问题汇总.md），为每个问题生成解决方案。

要求：
1. 每个问题对应一段解决方案，包括：问题名称、具体修复思路、实现步骤
2. 解决方案要结合物联网平台最佳实践（参考阿里云IoT、华为云IoT、腾讯云IoT等）
3. 区分高优先级和中优先级问题，高优先级问题给出详细方案，中优先级给出概要方案
4. 每个方案包含：是否需要改数据库表结构、是否需要改后端逻辑、是否需要改前端逻辑、影响范围
5. 对于代码重复问题，给出具体的重构思路
6. 对于UX问题，给出具体的交互改进方案
7. 对于安全问题，给出具体的加固方案
8. 实现步骤要具体到代码层面，说明改哪些文件的哪些函数/组件
```

## 生成任务清单提示语

```
你是一个AI编程助手。请基于已识别出的 ThingsPanel 物模型模块问题（详见 docs/任务/物模型相关产品问题汇总.md），生成一个完整的任务清单，用于指导 AI 自动完成代码改造。

要求：
1. 按优先级分组：高优先级、中优先级、低优先级
2. 每个任务包含：任务名称、任务描述、关联的问题编号、涉及模块（前端/后端/数据库）、验收标准
3. 任务之间如果有依赖关系，明确标注
4. 给出整体排期建议，按优先级顺序列出前5个最紧急的任务
5. 每个任务至少包含5个具体的子任务，便于 AI 按步骤执行代码改造
6. 标注哪些任务可以并行执行，哪些必须串行
7. 子任务描述要具体到代码层面，例如：修改哪个文件的哪个函数、增加哪个字段、删除哪个逻辑等
```
