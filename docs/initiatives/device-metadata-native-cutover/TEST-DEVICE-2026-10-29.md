## 接手核对补充（2026-10-29）

本清单记录的是局部候选功能，不代表设备菜单全部完成，也不应把功能缺失一概视为不需要报告。Community 当前源码已有历史查询、导出和模拟上报的旧实现，但尚未证明符合新接口的权限、分页、数据及运行时契约；相关原生链路仍待实现和验收。旧删除接口会同时删除历史和最新数据，不等同于仅删除最新值。

用户于 2026-10-29 进一步明确：凭据明文直接显示，不需要额外的受控揭示流程。此前只在创建时显示一次、要求单独 reveal/重新认证/理由的方案不再作为产品要求；普通登录与租户隔离仍须保留。**已实现（2026-10-29）**：`GET /api/v2/devices/{id}/credentials` 的每条凭据新增 `secret`（x509 与已撤销为 null，响应 no-store），OpenAPI `CredentialDetail`、前端连接页和后端集成测试已同步；“手工修改凭据”=导入指定密钥创建新凭据后轮换替换，页面和后端早已支持，不另设修改接口。凭据手工修改的既有需求不因本次决定取消。此前关于用户已同意不做删除的表述缺少可核实的用户决定，不应作为需求变更依据。

遥测实时连接已调整为首次读取结束后建立连接，并在连接成功及重连时发送设备订阅；设备切换会重建该组件。组件模拟测试通过，不等于真实浏览器、真实 MQTT 或真实后端验收。

## 先看这三条，避免误判
1. **运行时应用回执还没有接入（DM-RT-007）。** 启停、换模板、改编号、凭据轮换/撤销提交后，操作可能持续处于「待处理」；这是当前待解决的阻断项，不代表运行时已经生效。当前只能验证受理、元数据落库、刷新读回、幂等和权限。
2. **真实应用链路尚未在本轮验证。** 本机可访问 Docker，但现有容器状态及其镜像版本不能证明当前候选已部署并运行。
3. 新的元数据 HTTP 请求应走 `/api/v2/...`；遥测实时 WebSocket 当前仍使用 Community 路径，这是未完成的运行链接线，不应报告为全部原生。

## 要测的功能

| Tab | 操作 | 期望 |
|---|---|---|
| 期望消息 | 在「指令下发」里提交一条「上线后发送」命令，再到「期望消息」 | 列表出现该命令，状态「等待上线发送」；点取消后状态变「已取消」 |
| 期望消息 | 状态选「已过期」或「失败」 | 只显示对应状态；只有「等待上线发送」有取消按钮 |
| 连接 | 打开页面 | 「接入信息」卡片显示协议；接入地址未配置时显示「未配置」；凭据列表直接显示明文密钥（已撤销和证书类为空），接入信息卡片本身不显示密码 |
| 连接 | 创建一个新凭据，再对「已生效」的凭据点「轮换」 | 有待生效凭据时，确认框写明用哪个替换；没有则提示先创建。提交后提示「已提交」并带操作编号 |
| 连接 | 对任意未撤销凭据点「撤销」 | 确认后凭据变为「已撤销」，且不可恢复；再次撤销被拒绝 |
| 设置 | 「设备编号」填新编号和原因，点变更 | 提示「已受理」；刷新后当前编号更新；编号被占用时提示冲突 |
| 诊断 | 打开页面 | 顶部有各阶段的通过/失败/未知标签；上行、下行、存储显示「--」，不是 0 或 100% |
| 诊断 | 先下发一条会失败的命令 | 「最近失败记录」出现该命令 |
| 遥测 | 打开页面 | 显示当前值；页面顶部说明模拟上报、删除、历史曲线尚未接入 |
| 遥测历史 | 打开某个字段的历史表，默认最近24小时；选超过24小时的区间 | 表格按时间倒序分页；超过24小时提示「原始历史单次最多查询 24 小时」，不发请求 |

## 已知缺口（仍需跟踪）
- 删除最新读数：Community 不提供 cacheVersion，契约要求精确匹配，暂不实现。
- 历史读数：`GET /api/v2/devices/{id}/readings?kind=telemetry&identifier=..&from=..&to=..` 已接 Community 历史分页（原始样本、[from,to)、单次≤24h，设备遥测历史表已改用）；聚合（min/max/avg/sum/diff）、属性历史、历史曲线图和导出（DM-RT-018）仍未做。
- 模拟器：Community 旧实现存在，原生链路尚未实现和验收。
- 凭据明文直接显示已完成；手工修改通过导入密钥创建+轮换满足。
- 激活：任务书规定社区版不做。
