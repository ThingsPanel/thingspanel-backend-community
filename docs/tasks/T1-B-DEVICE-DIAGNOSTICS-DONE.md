# T1-B 设备诊断

- 设备诊断复用 Redis 中已有的累计统计键及字段。保留全局 diagnostics.enabled，设备调试开关仅控制详细日志。v1 统计查询要求鉴权和设备访问范围，前端以「累计」标识口径。
- 写端在内存按设备和字段合并计数，固定间隔用 Redis Pipeline 批量刷新。单条遥测按点位数增量累计，服务正常关闭时先尝试刷新再关闭 Redis。缓冲有界，异常或 Redis 故障时可能丢失部分待刷新计数。
- Mosquitto 可靠下行累计的是发布确认，遥测存储仅对已知失败累加失败点位。调试日志覆盖上行处理、遥测写入和下行发布，保留条数与 TTL，不含报文内容。
- 已移除窗口回执统计和索引迁移。Encore v2 继续提供诊断检查项，前端用已有的 Redis 统计接口读取累计计数。
- 定向验证覆盖 Redis 计数命令合并、没有前台 Redis I/O、诊断页累计数展示。此前在隔离 Redis 7 验证了设备日志写入脚本的开关、条数上限和过期。真实 MQTT 联调尚未完成。
