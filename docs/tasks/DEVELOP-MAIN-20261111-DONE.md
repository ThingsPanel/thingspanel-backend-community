## 发布边界

合并后的 push 仍自动测试和构建，但不自动改动服务器。部署需在主线 workflow_dispatch 明确选择发布，并先验收配套数据库、运行时身份、路由和设备数据。当前 c.thingspanel.cn 的 Gin、Encore 和通知核心保持 70bd7a1d，不随本次代码归并切换。

原因：旧栈的原生设备目录尚未承接社区设备数据；新前端依赖原生设备接口。仅发布页面会造成设备不可见。新增 file_storage、connector_runtime 等数据库及 hosted_services 也不能由代码合并推定已配置。

Encore 源码发布包同时携带 pkg/relational，避免本地 replace 在服务器缺文件。发布镜像包含已集成服务，实际托管服务和数据切换需要匹配运行配置。

develop 仍含历史 SQL 翻译层及未结事项，本次保留既有实现，不新增其使用面；不能据源码合并宣称完成所有数据库组合或全部真实插件验收。
