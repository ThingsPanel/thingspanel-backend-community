# 社区 Mosquitto 一期 AC 逐项执行台账（2026-10-20）

依据：[实施计划 §11](gmqtt-replacement-plan-2026-10-19.md#11-完整验收用例与证据规范)。本表保留长期跨产品计划中的执行描述和断言；社区一期只执行适用于 Mosquitto 社区版的子集。73 个长期 AC 中，61 个社区适用 ID 逐项跟踪；二期 OUT_OF_SCOPE 共12项：AC-V01–V04、AC-E01–E07的11项企业专项，以及仅适用于EMQX纯native profile的AC-D03。D03不计社区一期欠项、不算PASS，也不减少社区其余迁移/撤权断言；AC-D01/D02/D04–D06仍按社区Mosquitto profile验收，其他集群等子句依G0范围判定。只有覆盖单项全部计划步骤并满足通过标准才可记 PASS。当前仅有分项/子场景证据，因此本表没有把任何局部结果扩大为完整 AC PASS。2026-10-20新增计划API/service、单次原生Mosquitto计划命令子项、两次SIGKILL重投记录与静态SBOM边界见[当前验收增量清单](gmqtt-community-acceptance-delta-2026-10-20.md)；73项要求及本表判定未因局部测试而降低。

## 本轮具体验证与边界

- 原生 ingress E2E 已分别验证真实 EVT、ATTR、TEL 样本到自动化持久命令、Paho 测试设备收到并 ACK；见 [native ingress E2E](gmqtt-evidence-2026-10-19/native-mosquitto-owner-ledger-e2e.md) 和 [automation native command E2E](gmqtt-evidence-2026-10-19/automation-native-command-e2e.md)。这是本地软件链子项，不证明物理设备动作，AC-C12 仍 PARTIAL。
- 状态投影/quarantine 的真实 PG 回归见 [quarantine regression](gmqtt-evidence-2026-10-19/broker-quarantine-regression.md)；时间边界回归见 [state boundary regression](gmqtt-evidence-2026-10-19/broker-state-time-boundary-regression.md)。
- Linux MQTT3/5 离线持久会话与受控 Broker 重启矩阵见 [Linux command-frame QA](gmqtt-evidence-2026-10-19/linux-command-frame-qa.md)。最大认证并发仍需 barrier-controlled overlap；OS崩溃/断电未覆盖。
- automation PostgreSQL 子项已覆盖每设备 burst=10、按 1 token/3 秒补充、不同设备隔离及失败事务不消耗 token；状态 activity/timeout、freshness unknown 子项通过 PG 测试。SQL011 safe-voucher、SQL012 route-change 也有 PG/迁移相关测试；均非对应 AC 全覆盖。
- 机器自动命令不再是“新profile一律拒绝”：带可信策略快照/proof 的同源 EVT/ATTR rule command 已经由 SQL009 planner、既有 dispatcher 和 native MQTT 设备 ACK；缺 proof、跨设备条件及 unsupported 动作仍拒绝或记录 unsupported。AI场景、授权矩阵、人效/成本等验收仍未通过。
- QA schema检查器对编号迁移动态排序；`brokerqa`私有 schema fresh/repeat 通过，策略快照列5个、动作审计列11个，并验证 migration 014 命名索引存在；检查器不执行生产迁移，也不核验索引定义或运行效果。

- [计划命令原生Mosquitto E2E](gmqtt-evidence-2026-10-19/planned-command-native-mosquitto-e2e-2026-10-20.md) 补充一条preview→真人授权→持久命令→Paho测试设备收包/ACK链。语义端为`httptest` stub，设备ACK不等于物理效果；AC-A01/A02及R04仍未覆盖完整标准。
- [SIGKILL记录](gmqtt-evidence-2026-10-20/sigkill/) 有 adapter subscriber 子进程被杀、broker 持续运行时的重投/去重子项，包含有、无 `source_event_id` 两种结果；无 source ID 的 `-count=2` 只归档最后一轮原始日志。[SBOM provenance](gmqtt-evidence-2026-10-20/sbom/provenance.json) 是单个冻结本地镜像静态清单。两者均不证明 Mosquitto 进程故障、硬重启/存储故障或生产制品认证。
- SQL012切换工具已有 `tp-broker-cutover` reviewed-plan入口；freeze持久化actor/raw plan hash，prepare/activate/rebase在同事务追加actor标签/raw hash的`operator_apply`事件，成功重试可能追加事件。该标签不是签名身份或审批证明；membership retirement和双cell真实灰度回退仍待实测。`tp-broker-route`仍为只读工具，见[CLI说明](../deploy/mosquitto-community/CUTOVER-CLI.md)。
- Telemetry evidence返回trusted processed记录；现有writer没有独立reported timestamp，响应会标`reported_at:null`与`reported_time_available:false`，单位缺失时`unit_known=false`，见[遥测证据API](gmqtt-evidence-2026-10-19/community-telemetry-evidence-api.md)。
